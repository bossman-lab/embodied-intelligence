# 极夜 T2 (DeskOne T2) 硬件规格

| 组件 | 参数 |
|:----|:----|
| CPU | AMD Ryzen AI 9 HX370 (12核/24线程, 最大加速频率 5.1GHz) |
| RAM | 96GB DDR5 |
| iGPU | AMD Radeon 890M (RDNA 3.5, 16 CU) |
| 存储 | 1TB NVMe SSD |
| 网络 | 2.5GbE LAN |
| 接口 | OCuLink (支持外接 GPU) |
| 系统 | Windows 11 Pro |
| IP | 192.168.3.175 (DHCP) |

## 性能特征

- CPU 多核性能接近桌面级 Ryzen 9
- iGPU 约等于 GTX 1050 Ti (纯计算)
- 96GB 内存可运行大模型推理 (Q4 量化 47B 模型)
- OCuLink 接口支持外接 RTX 4090 级别 eGPU
