# Era0 技术路线拆解与具身智能学习指导

> 星动纪元 Era0 在 RoboChallenge 登顶，背后是两年技术积累：HiRT 分频 VLA → VPP 视频预测 → Ctrl-World 可控生成 → VLAW 闭环进化。本文拆解这条技术路线，并给出系统化学习路径。

---

## 一、Era0 是什么？为什么值得学？

2026 年 5 月，星动纪元（Robotera）的 **Era0** 模型在 RoboChallenge Table30 评测中登顶：

| 指标 | Era0 | 说明 |
|------|------|------|
| 综合成功率 | **64.33%** #1 | 30 项桌面操作任务的综合表现 |
| 过程分 | **76.34** #1 | 动作质量评分 |
| 最高难度任务 | "做三明治""擦桌子"**唯一非零** | 其他参测模型全部得零分 |
| 30 项中第一名 | **17 项** | 过半任务最优 |

参测对手包括 Physical Intelligence 的 π0/π0.5、微软 CogACT 等全球最强具身模型。RoboChallenge 已纳入 CVPR 2026 和 ICRA 2026 两大顶会。

**但比榜单成绩更重要的，是它已经在物流行业真机部署**——中国邮政、顺丰，全国 5 省 10+ 物流中心常态化运营。

## 二、技术演进路线

Era0 不是一蹴而就的。它的技术谱系是一条清晰的演进链：

```
2024.09  HiRT 分频VLA          ← 提出快慢分层架构
         └─ 论文：arxiv.org/abs/2409.08204

2024.12  VPP 视频预测策略       ← 开源，用互联网视频扩展数据
         └─ 论文：已开源

2025.10  Ctrl-World             ← 与斯坦福 Chelsea Finn 团队合作
         └─ 代码：github.com/Robert-gyj/Ctrl-World
         └─ 效果：陌生场景下游任务平均成功率提升 44.7%

2026.02  VLAW                   ← 世界模型 × VLA 协同进化闭环
         └─ 论文：arxiv.org/abs/2602.12063
         └─ 效果：π0.5 + VLAW 基准任务成功率大幅提升

2026.05  Era0                   ← RoboChallenge Table30 #1
```

## 三、核心技术栈拆解

### 3.1 HiRT — 架构层：快慢脑分离

这是 Era0 最核心的设计决策。不是用一个模型做所有事，而是分层：

| 层级 | 模型规模 | 频率 | 负责 |
|------|---------|------|------|
| **慢脑（世界模型）** | 7B 参数 | 低频 | 场景理解、任务规划、物理推理 |
| **快脑（执行模型）** | 40M 参数 | 高频（200Hz） | 实时动作生成、关节控制 |

两者通过 **latent 向量** 连接。7B 的世界模型输出高层意图（"下一步往哪走"），40M 的执行模型快速翻译成电机指令。

**设计洞察**：具身智能不需要一个模型什么都做。把"理解物理世界"和"控制电机"拆开，各用最合适的规模。星动纪元是全球首个提出这种分频 VLA 架构的团队，后续 PI、Figure、Google、NVIDIA 相继跟进类似路线。

### 3.2 VPP — 数据层：视频预测突破数据瓶颈

传统 VLA 的最大瓶颈是机器人动作数据极度稀缺——遥操作采集一条轨迹成本极高。VPP 的解决方案：

> 用视频生成模型作为"隐式世界模型"——给定初始帧和语言指令，模型生成目标状态的视频帧，然后从视频帧反推动作。

这相当于把可用数据从"机器人遥操作轨迹"（全球约几百万条）扩展到"互联网视频"（数十亿小时）。

### 3.3 Ctrl-World — 基础世界模型

与斯坦福 Chelsea Finn 团队合作开发的可控生成世界模型。解决了两个核心问题：

1. **物理保真度低**：世界模型擅长"看起来对"，但做不到"物理上对"
2. **盲目乐观**：只用成功轨迹训练，导致模型自动"脑补"失败为成功

Ctrl-World 提出**动作条件视频生成**——输入当前观察 + 动作序列，生成对应的未来视频帧，显式建模动作对物理世界的因果影响。

### 3.4 VLAW — 闭环优化：世界模型 × VLA 协同进化

这是当前 Era0 技术栈的巅峰，也是**最值得深挖的部分**。

核心问题：世界模型不准确 → VLA 在其中学不到好东西 → 世界模型更差。VLAW 的解法：

```
          真实轨迹（成功+失败）
                ↓
   世界模型校准（不再盲目乐观）
                ↓
   生成大规模合成轨迹（500条/任务）
                ↓
   混合真假数据训练 VLA 策略
                ↓
   策略在真实世界产生更优质轨迹
                ↓
               ↻（闭环迭代）
```

**四步工程化流程：**

1. **校准世界模型**：同时用**成功与失败**的真实轨迹微调，加入原始 DROID 数据集防止遗忘
2. **自动评判轨迹质量**：基于 Qwen3-VL-4B-Instruct 微调视觉-语言奖励模型
3. **大规模合成数据生成**：每个任务生成 500 条合成轨迹
4. **策略优化**：混合真实成功轨迹 + 合成成功轨迹，使用加权回归目标

**实验验证**：在 DROID 平台 5 类复杂接触任务上测试（堆叠积木、打开书本、擦白板、舀颗粒、画圆），VLAW 在每类任务上持续优于 Filtered BC 和 DSRL 基线。

## 四、系统化学习路线

按照"精通五层"框架设计：**跑通 → 拆解 → 参数 → 边界 → 封装**。

### 阶段一（2 周）：跑通 — 建立全局认知

**目标**：理解 VLA 的完整概念，能运行一个基本 demo。

**必读论文（按顺序）：**

| 论文 | 发表 | 为什么读 |
|------|------|---------|
| RT-2 | Google 2023 | VLA 奠基之作，理解"动作 token"概念 |
| π0 | PI 2024 | Flow Matching 做 50Hz 动作，Era0 对标对象 |
| [HiRT](https://arxiv.org/abs/2409.08204) | 星动纪元 2024 | Era0 架构起点，快慢脑 |
| [Ctrl-World (GitHub)](https://github.com/Robert-gyj/Ctrl-World) | 清华+Stanford 2025 | 世界模型可控生成 |
| [VLAW (arxiv 2602.12063)](https://arxiv.org/abs/2602.12063) | 清华+Stanford 2026 | VLA+世界模型协同进化 |
| [World Model Survey (arxiv 2605.00080)](https://arxiv.org/abs/2605.00080) | NTU 2026 | 43页综述，系统性框架 |

**动手 Lab**：
- 用 OpenVLA 跑通一个抓取任务（本地或仿真）
- 在 DROID 数据集上做一次简单的 VLA 推理验证

### 阶段二（3 周）：拆解 — 理清每个模块

**模块 A：VLA 基础**
- 动作空间表示：离散动作（RT-2）vs 连续动作（π0）
- Flow Matching 与 Diffusion Policy 的原理
- 对比 π0（单模型）vs π0.5（分层架构）vs HiRT（分频 VLA）

**模块 B：快慢脑架构**
- HiRT 的 latent 向量如何连接 7B 和 40M 两个模型
- 为什么是 7B/40M 这个比例？对比 Figure Helix（VLM→200Hz）
- 慢脑的刷新频率如何影响任务成功率

**模块 C：世界模型**
- 从"生成视频"到"预测物理后果"的跃迁
- 动作条件生成（Ctrl-World）vs 无条件视频生成
- VLAW 的真实数据校准机制

**模块 D：数据飞轮**
- 遥操作数据 → 互联网视频 → 世界模型合成数据
- VPP 的技术路线：视频生成 → 动作反推
- RoboChallenge 比赛策略：如何在有限真实数据下最大化泛化

### 阶段三（1 周）：参数 — 理解关键设计选择

| 设计选择 | Era0 的做法 | 替代方案 | 为什么这么选 |
|----------|------------|---------|-------------|
| 世界模型规模 | 7B | 0.5B / 70B | 平衡预测精度和推理速度 |
| 执行模型规模 | 40M | 400M | 200Hz 实时控制需要超低延迟 |
| 每轮合成数据量 | 500 条/任务 | 100 / 2000 | 500 是保质保量的经验值 |
| 奖励模型 | Qwen3-VL-4B 微调 | 规则打分 | 比规则更灵活，比大型 VLM 更轻量 |
| 训练混合比 | 真实+合成混合 | 只真实/只合成 | 消融实验证明混合最优 |

### 阶段四（0.5 周）：边界 — 知道它解决不了什么

1. **Era0 擅长操作，不擅长导航**—Table30 全是桌面操作，没有移动操作
2. **依赖预先定义的任务空间**—三明治的食材位置是预设的，不是随机探索
3. **世界模型仍有幻觉**—长时序（>30 秒）的物理预测准确性快速下降
4. **数据效率有天花板**—每个新任务仍需 50 条真实轨迹校准
5. **硬件绑定**—测试平台是 UR5/Franka + 特定夹爪，迁移到新硬件需适配

### 阶段五（0.5 周）：封装 — 形成可复用的知识框架

到了这个层面，你应该能给出：

- **一句话**：Era0 = 7B 世界模型预测物理后果 + 40M 执行模型翻译成动作，通过真实数据校准形成闭环
- **一个图**：VLAW 闭环流程图（真实 rollout → 世界模型校准 → 合成数据生成 → 策略优化 → 闭环）
- **一个判断框架**：看到新的具身模型，自动分析它的架构在哪一层、为什么这么设计、解决了什么问题

如果要在 existing embodied-intelligence 课程体系中融入 Era0 技术线路，推荐如下模块编排：

| 模块 | 时长 | 先修 | 核心内容 |

| Module 2: 快慢脑架构 | 2 周 | Module 1 | HiRT 深入分析，快慢脑 lab（2B VLM + 10M MLP 原型） |
